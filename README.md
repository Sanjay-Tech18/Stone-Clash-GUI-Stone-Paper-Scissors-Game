# 🪨 Stone Clash – GUI Stone Paper Scissors Game

A simple and interactive **Stone Paper Scissors GUI Game** built using **Python Tkinter**. Challenge the computer, track scores, and enjoy a clean graphical interface.

## 🎮 Features

✅ Interactive GUI using Tkinter  
✅ Play Stone, Paper, Scissors against Computer  
✅ Live Score Tracking  
✅ Random Computer Choices  
✅ Reset Game Option  
✅ Beginner-Friendly Python Project  
✅ No External Libraries Required

## 🎯 Game Rules

- **Stone beats Scissors**
- **Scissors beats Paper**
- **Paper beats Stone**
- Same choice = **Tie**
